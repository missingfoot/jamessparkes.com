# FIXR Platform

## Overview
FIXR is a leading ticketing platform in the UK, providing comprehensive solutions for event organizers and attendees. The platform spans web, iOS, and Android applications, serving millions of users annually.

## Role & Responsibilities
As Senior UX/UI Designer, I led the design of FIXR's ticketing platforms across web and mobile applications. Key responsibilities included creating intuitive user flows, developing a cohesive design system, and ensuring a seamless cross-platform experience.

## Key Achievements
- Redesigned the ticket purchasing flow, reducing abandonment rate by 25%
- Developed a comprehensive design system used across all platforms
- Implemented rapid prototyping methodology for faster iteration cycles
- Led the UX research initiative to improve platform usability
