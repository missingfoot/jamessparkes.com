## The process

This project (along with [Tab tools](/personal/tab-tools)) is one of a series of personal projects where I lean on AI-assisted IDEs like Cursor to accelerate development, while personally driving the project from problem definition through to release rather than just focusing on UX design:

<KVGroup>
  <KV term="Identify the problem" desc="Started with a real-world issue: full-page translation tools breaking layout and stripping away useful context." />
  <KV term="Draft requirements" desc="Defined features and success criteria, using AI to generate early concepts and prototypes." />
  <KV term="Design & prototype" desc="Hand-coded the CSS for a lightweight tooltip overlay so the extension never disturbs the host site's design." />
  <KV term="Develop the MVP" desc="Built the extension from scratch, focusing on the hover-translate interaction before layering on caching and throttling." />
  <KV term="Test & iterate" desc="Tested with friends and family and refined the caching thresholds and tooltip behaviour based on their feedback." />
  <KV term="Document & reflect" desc="Kept a readme and roadmap so I could pick the project back up between AI sessions without losing context." />
</KVGroup>

## Development highlights

<KVGroup>
  <KV term="Hover-based translation" desc="Hover over text to see its translated equivalent instantly." />
  <KV term="Caching & throttling" desc="Prevented runaway API costs by limiting requests and storing frequent translations." />
  <KV term="Subtle UI" desc="A tooltip overlay preserves the native look and feel of the website." />
</KVGroup>

## Result & impact

<KVGroup>
  <KV term="Language learning" desc="Retains the page's native language while translating only words or phrases on demand, so users can learn new languages from exposure, context, and reinforcement via unintrusive translations." />
  <KV term="Future roadmap" desc="Refine translation accuracy, usability, and performance. Add smarter language detection, expanded OCR functionality for images, a domain-specific caching system, and collaborative cloud integration for sharing translations so fewer AI requests are needed." />
</KVGroup>

## Conclusion

Building UI Translator gave me a 360-degree view of product creation, from defining the problem through to shipping and gathering real user feedback. It reinforced how much AI-assisted development rewards clear documentation and requirements, much like good teamwork, and it's a workflow I've since carried back into professional projects.
